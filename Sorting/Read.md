# 🔄 Sorting Algorithms & Problems in C++

This repository contains implementations of basic sorting algorithms and popular sorting-related coding problems solved in C++.

---

# 📂 Files Included

## 🟢 Sorting Algorithms

### 1. Bubble Sort
**File:** `bubble_sort.cpp`

- Repeatedly swaps adjacent elements if they are in the wrong order.
- Simple beginner-friendly sorting algorithm.

### 2. Selection Sort
**File:** `selection_sort.cpp`

- Finds the minimum element and places it at the correct position.
- Performs fewer swaps compared to Bubble Sort.

### 3. Insertion Sort
**File:** `insertion_sort.cpp`

- Builds the sorted array one element at a time.
- Efficient for small or nearly sorted arrays.

---

# 🧠 LeetCode / DSA Problems

### 4. Contains Duplicate
**File:** `contains_duplicate.cpp`

- Checks whether an array contains duplicate elements.
- Implemented using sorting approach.

### 5. Merge Sorted Array
**File:** `merge_sorted_array.cpp`

- Merges two sorted arrays into a single sorted array.
- Common two-pointer based problem.

### 6. Next Permutation
**File:** `next_permutation.cpp`

- Finds the next lexicographical permutation of an array.
- Uses pivot, swapping, and reversing technique.

### 7. Sort Colors
**File:** `sort_colors.cpp`

- Sorts an array containing only 0s, 1s, and 2s.
- Basic sorting approach.

### 8. Sort Colors (Dutch National Flag Algorithm)
**File:** `sort_colors_dnf.cpp`

- Optimized solution for Sort Colors problem.
- Uses three pointers:
  - low
  - mid
  - high

- Time Complexity: O(n)
- Space Complexity: O(1)
